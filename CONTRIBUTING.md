# Contributing to LyricsOSC

Thanks for helping! Bug reports, translations, code and art are all welcome.

## Before you start

- By opening a pull request you accept the [CLA](CLA.md). Add this sentence to the PR description:
  *"I have read the LyricsOSC CLA and I agree to it."*
- The **code** is licensed under **GPL-3.0-or-later**. Forks and modified versions must stay under the same licence and keep the copyright notices.
- The **mascot and artwork** have their own licence ([app/assets/LICENSE-ART.md](app/assets/LICENSE-ART.md)). Art contributions (new poses, icons…) are welcome. By submitting them you agree they join the project's artwork under that licence (see the [CLA](CLA.md)).
- Branch from `master` and open the pull request against `master`.

## Development setup

### Desktop app (`app/`)

```bash
cd app
cargo run                       # debug build
cargo test                      # tests: title cleanup, OSC encoding, translations, versions

# Voice engine (Python + faster-whisper) installed into the current folder
powershell -ExecutionPolicy Bypass -File scripts/setup_voice.ps1 -InstallDir .   # Windows
./scripts/setup_voice.sh .                                                       # Linux
```

`LYRICSOSC_TAB=about|voice|chatbox|monitor|log` opens the app on a given tab (handy for screenshots).

## Project layout

| Path | What it does |
|---|---|
| `src/main.rs` | Window (egui), tabs, banner, settings UI |
| `src/engine.rs` | Main loop: player → lyrics → transcription → chatbox / Axis |
| `src/media/` | Now playing: `windows.rs` (SMTC), `linux.rs` (MPRIS) |
| `src/audio/` | Audio capture: `windows.rs` (WASAPI, per app), `linux.rs` (PulseAudio/PipeWire) |
| `src/lyrics.rs` | LRCLIB lookup, LRC parsing, title cleanup |
| `src/whisper.rs` | Starts and talks to the Python voice process |
| `src/osc.rs` / `src/axis.rs` | VRChat chatbox (OSC) and Axis addon output |
| `src/monitor.rs` | CPU / RAM / VRAM monitor |
| `src/update.rs` | Update check (website, then GitHub) |
| `src/i18n.rs` + `locales/` | Interface translations |
| `python/whisper_sidecar.py` | Speech to text (faster-whisper) |
| `scripts/` | Voice setup and release builds |
| `installer/` | Inno Setup (.exe), WiX (.msi), Linux (install.sh) |
| `tools/` | Generators: translations, banner, icons |

## Translations

The translations are generated by `app/tools/gen_locales.py`. To fix a string, edit the
generator (or the JSON in `app/locales/`), then run `cargo test` in `app/`: it fails if a key is missing.
To add a language, add it to the generator and to `LOCALES` in `app/src/i18n.rs`.

## Style

- `cargo fmt` and `cargo clippy` before sending.
- Keep platform code under `#[cfg(windows)]` / `#[cfg(target_os = "linux")]`.
- User-facing text goes through `i18n::t("key")`, never hard-coded.
- Code comments in English.
